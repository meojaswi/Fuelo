# Fuelo polished frontend

Built around the supplied Fuelo-adapted design direction:
- Primary: #CC8066
- White background
- #191C21 dark surface
- #334155 accent
- #111827 primary text
- #4B5563 secondary text
- #E5E7EB borders
- 8px card/control radius, pill selectors
- Inter for interface/display and JetBrains Mono for technical labels

Run:
npm install
npm run dev

Set:
VITE_API_BASE_URL=http://localhost:5000/api

Backend API route assumptions are documented in the original starter. Adjust only src/api if your backend paths differ.
